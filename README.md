# 🎬 MovieZoom

MovieZoom is a console-based movie search application developed in C++ as part of a university programming project. The application allows users to browse and search a collection of movies through a simple command-line interface while demonstrating fundamental object-oriented programming concepts and data management techniques.

---

## Features

- Search movies by title
- Display movie information
- Console-based user interface
- Efficient movie data handling
- Object-oriented design

---

## Technologies Used

- C++
- Visual Studio Code
- Standard Template Library (STL)

---

## Project Structure

```
MovieZoom.cpp        # Main application source code
.vscode/            # VS Code configuration files
```

---

## Getting Started

### Prerequisites

- C++ compiler (GCC, MinGW, or MSVC)
- Visual Studio Code (optional)

### Compile

```bash
g++ MovieZoom.cpp -o MovieZoom
```

### Run

```bash
./MovieZoom
```

On Windows:

```bash
MovieZoom.exe
```
